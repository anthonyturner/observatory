# Changelog

All notable changes to observatory are recorded in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
How to add an entry: [docs/changelog.md](docs/changelog.md).

## [Unreleased]

### Removed

- The Review Queue's sound no longer plays a continuous background drone. Space is silent, so with sound on the sky stays quiet until something happens on it: a star's ping, a meteor's crackle, a satellite's beep, a merge's boom. The off-key tone that grew with blocked pull requests went with it ([#553](https://github.com/anthonyturner/observatory/issues/553)).

### Added

- Each project has a **Milestones** screen, the last tab, showing each open milestone as a planet in transit along its own lane toward its due date: the further along, the more of its issues and pull requests are done, and its air reddens as the date nears and passes (blue with time to spare, amber within a week, red once overdue, green when nothing is left open). Each planet links to the milestone on GitHub, and the **List** view gives every open milestone, and the ones closed lately, with its open and closed counts, progress, due date and its issues and pull requests in a fold. Beside them, the project's latest **Discussions** are listed by category with whether each is answered, linked to GitHub. A project with no milestones or with Discussions off says so plainly, and its Milestones tab recedes when it has neither ([#569](https://github.com/anthonyturner/observatory/pull/569)).
- Each project has a **Deployments** screen, a new tab after Insights, showing each environment (such as Vercel's Production and Preview) as a launch pad: its latest deployment is a beacon on a beam above it, green when live, amber while building, red when it failed, and the seven before it a fading trail climbing away. Every light links to its deployed site, or its commit when it has none, and the **List** view gives each environment's deployments newest first with their status, commit, site and log. A pull request's screen now shows its head's preview deployment and a link to open it ([#568](https://github.com/anthonyturner/observatory/pull/568)).
- Each project has an **Insights** screen, a new tab after Security, charting the last twelve weeks: commits a week to the default branch, the median time from opening a pull request to merging it a week (as the Review Queue's weekly retro works it out), the top contributors by commits, bots marked, and the pull requests each agent merged where the Agents report cards attribute them. Traffic shows the last fourteen days of views and clones with their unique visitors. Hover any bar for its detail, or open **Table view** under a chart for the same numbers as a table. A row of stars in the header, one a week sized by its commits, gives the quarter at a glance. While GitHub is still counting a repository's statistics the screen says so and offers **Check again**; when the token cannot read traffic it says it needs push access. Visitors to the hosted preview see everything but the traffic ([#567](https://github.com/anthonyturner/observatory/pull/567)).
- An **Inbox** at `/inbox` lists your unread GitHub notifications across every repository, grouped by repository and then by reason (review requested, mentioned you, assigned to you, CI runs and so on), what waits on you first. A pull request or issue in a project Observatory charts opens its PR screen or issue window on the Review Queue; anything else opens on GitHub. Mark one or all read from the page. Home's top bar has an Inbox link with the unread count. If the GitHub token cannot read notifications, the page says which scope it needs. On the hosted site only the signed-in owner sees the Inbox, never a preview visitor ([#564](https://github.com/anthonyturner/observatory/pull/564)).
- Each project has a **Depth** screen, a new tab beside Library, that draws every TypeScript file of its local clone as a planet, after John Ousterhout's idea of deep modules. A planet's core is the work the file hides (its statements) and its ring is what a caller has to learn (exported names, their parameters, a class's public members, an interface's fields). A deep module is nearly all core; a shallow one, such as a wrapper or a file that only re-exports, is a hollow ring round a speck. Hover or Tab to a planet (then the arrow keys) to see its three numbers, its verdict and the design principle behind it; filter by path or verdict, or switch to **List**, shallowest first. Files are grouped by folder; specs, test helpers, entry points and files of only types get no planet. It reads the code on your own machine, so it needs a clone of the project and is not in the hosted preview ([#558](https://github.com/anthonyturner/observatory/pull/558)).
- Each project has a **Journal** screen, a new tab beside Actions and Library, that lists what each self-review taught, newest first: the first version, the feedback, what changed on the redo and why, and the design principle it taught, linked to the pull request. Principle chips (labelled from the Principle of the day's list) narrow the list to the lessons that taught one. A lesson appears once a self-review comment carries a `## Second draft` section, in the format `docs/agent-workflows/qa-review.md` gives; earlier reviews have none, so the Journal starts empty and says so. Visitors to the hosted preview can read public projects' journals ([#555](https://github.com/anthonyturner/observatory/pull/555)).
- Each project has a **Security** screen, a new tab beside Library, listing its open Dependabot, code-scanning and secret-scanning alerts as one list, most severe first. Each alert shows its kind, grade, package or file, how long it has been open, and links to GitHub. The tab shows how many are open. Above the list, each of the three says how many it holds, or, in a plain line, why it could not be read: the feature is off or not set up, or the token lacks a scope, which it names. **Sky** shows the same alerts as hazards in belts round the project's world, the worst innermost and the world's air in the worst one's colour. A secret's value never leaves the server, and visitors to the hosted preview see only the counts ([#506](https://github.com/anthonyturner/observatory/pull/506)).
- Moving sounds in the Review Queue now follow their motion with a gentle Doppler shift (at most three semitones either way), read from the positions the sky draws. A merged pull request's streak gets a soft whoosh that rises as it comes toward you and drops as it leaves, a meteor's crackle is a little higher for the way it fell, and a satellite's beep is higher on the side of its orbit coming toward you and lower going away. Motion off means no shift, and sound off means no sound ([#552](https://github.com/anthonyturner/observatory/pull/552)).
- On the Review Queue, a meteor streaks in and lands on each star whose pull request has new commits since you last looked, so you can see at a glance where new work landed. More commits make a brighter, longer streak; a pull request whose branch was rewritten gets one too, and at most twelve fall, the biggest changes first, once the sky has arrived. With sound on, each landing crackles softly on the side of the screen the star is on. With motion off there is no streak, only a brief glint on the star ([#541](https://github.com/anthonyturner/observatory/pull/541)).
- Live Claude Code agents orbit the Review Queue as small satellites, on your own machine: one round the star of the pull request whose branch it is working on, or along the top of the sky when none matches. Its light blinks faster while the agent is working and slower while it waits for you or is quiet, and hovering names the agent and its state. With sound on, each gives a soft Sputnik-style beep at the same pace, panned across the sky and never more than a few a second in all. Motion off parks them and holds the light steady; a crew's run stays its ship ([#543](https://github.com/anthonyturner/observatory/pull/543)).
- A pull request that merges now goes out of the Review Queue as a **supernova**: a white-gold flash and one ring of dust where its star stood, then it streaks away as before. With the star map's sound on, a deep boom and a fading shimmer play with it, from the side of the screen it happens on. With motion off you get a brief flash and the sound, but no ring ([#542](https://github.com/anthonyturner/observatory/pull/542)).
- Home shows a **Principle of the day** under the skills: one of John Ousterhout's software-design ideas, what it means in a sentence or two, and a question to ask yourself today, such as “Design it twice: what was your second idea today?”. It stays the same all day and moves on to the next one each day, round all eighteen; **Previous** and **Next** step through the rest and **Today's** comes back. Ask Jev “what's today's principle?” to hear it ([#525](https://github.com/anthonyturner/observatory/pull/525)).
- The Review Queue shows **tactical weather**: grey cloud and debris swirl round a pull request whose added lines carry design red flags (a catch that discards the error, a method that only forwards to another, a lint or type check switched off, a TODO with no issue), from a thin haze for one stray TODO to a storm with lightning for many or grave ones. A clean pull request stays clear. Its card lists each flag with its file and line and the design principle it breaks. The scan reads TypeScript and JavaScript patterns, skips tests, and can miss or mistake one; each diff is read once per push. Visitors to the hosted preview see no weather for private projects ([#523](https://github.com/anthonyturner/observatory/pull/523)).
- Jev carries out Review Queue commands however they are put, when the quick matcher can't: “get rid of the conflicted one in beta”, “park the login fix till next Monday” or “have someone sort out the failing checks on 412” now work with Jev on. He can say what's blocking, open a pull request, snooze it until a date, dismiss it and send a crew, finding the pull request by its title when you don't give its number. Snoozing, dismissing and sending a crew still ask yes or no first, aloud and with buttons, exactly as the typed commands do; clear commands are still matched instantly without a model, and the “I heard” reply is now for when Jev is off ([#516](https://github.com/anthonyturner/observatory/pull/516)).
- Each project has a **Library** screen, a new tab beside Queue, Releases and Actions, for reading its documentation in Observatory. It reads the project's wiki when it has a public one, following links from Home, and otherwise its README and every Markdown file in `docs/`. Pages sit in an index drawn as a star chart, one constellation per shelf and each star sized by the page's length, beside a text column set for long reading, with an **On this page** list of headings. Search narrows the pages by title and text, showing where each matched. Links between pages stay in the Library, images GitHub hosts show inline, every page has its own address, and the arrow keys walk the index. Visitors to the hosted preview can read public projects' libraries ([#504](https://github.com/anthonyturner/observatory/pull/504)).
- The repository's [wiki](https://github.com/anthonyturner/observatory/wiki) mirrors the README, tech stack, sky visuals, this changelog and the decision records, refreshed on every merge to main, with a sidebar and links that stay on the wiki. Each page says which file to edit instead, and pages written by hand on the wiki are left alone ([#499](https://github.com/anthonyturner/observatory/pull/499)).
- An agent's page at **/agents** has an **Activity** tab: a live feed of what the agent says and does, its words, tool calls and their results, new rows arriving at the bottom every 3 seconds while it works and every 15 while it is quiet or waiting. The view follows the newest rows unless you scroll up, when **Jump to latest** brings you back. Long tool inputs and results arrive cut short, and Claude's thinking and Claude Code's own bookkeeping never leave your machine. The hosted site says agents show only on your own machine ([#498](https://github.com/anthonyturner/observatory/pull/498)).
- After “what’s blocking?”, Jev asks whether you want to work on one: he can open it or send a crew. Name it however comes naturally, typed or by push-to-talk: its number, its place in the list (“the first one”, “number two”), or its project and title words (“the observatory one about the playlist”). Ask to “send a crew”, “assign it to a crew member” or “get a crew on it”; Jev asks yes or no first, aloud and with buttons, then sends the crew the card’s Send crew would. A pull request that isn’t failing or conflicted gets an offer to open it instead, and when the words fit more than one he names them and asks which. “Send a crew to 412” works without the list too. Typed answers to Jev’s open question now work as spoken ones do. On your own machine only ([#496](https://github.com/anthonyturner/observatory/pull/496)).
- Each project has an **Actions** screen, a new tab beside Queue and Releases, showing its GitHub Actions workflows and recent runs. Each workflow is a lane running back from the present, and its runs are stars along it, newest nearest and sized by how long they took. Failed runs flare red, runs still going pulse, and runs that passed only on a rerun are ringed in amber as flaky. Filter by workflow, branch and status, or switch to **List**. Pick a run to see its branch, trigger, who started it and how long it took, plus its jobs and the steps that failed, each linked to GitHub. The owner gets a **Rerun failed jobs** button on a failed run; visitors to the hosted preview see the runs but no button. Workflows with no recent run are named under the list. Each project card on Home gains an **Actions** link whose dot shows whether CI on the default branch is passing, failing or running ([#494](https://github.com/anthonyturner/observatory/pull/494)).
- An agent's page has a **Changes** tab showing the code it has changed, read from git in the folder its transcript names. It covers committed, staged, unstaged and new files, edits made through shell commands included. Changes are compared with where its branch left origin/main, as of the last fetch: the tab names the folder, the branch and the base, and never fetches. It reads again on Refresh, and every 30 seconds while the agent works. Binary files are listed but not shown, and a large diff is cut short and says so. It links the open pull request on the same branch, warns when the folder is the shared main checkout, and shows only the committed changes once a worktree has been removed. Each case where there is nothing to show gets its own plain note ([#497](https://github.com/anthonyturner/observatory/pull/497)).
- See the Claude Code agents running on your machine at **/agents**: each session and subagent shows its project, branch, folder, title, when it last wrote and its last tool call, and whether it is working, waiting for you or quiet for so many minutes. Agents waiting for you come first, and sessions started with `claude -p` are tagged headless. An **Agent sessions** link on Home counts them all, and one on the Review Queue counts that repository's. Each agent opens its own page, which says when it is no longer running. The hosted site says agents show only on your own machine ([#493](https://github.com/anthonyturner/observatory/pull/493)).
- Each project has a **Releases** screen, reached from the new **Queue · Releases** tabs at the top of its pages. Its releases sit along a trajectory through the night sky, oldest far off and newest at the leading edge, each a star sized by how many pull requests it shipped and coloured by how far the version moved, with those pull requests circling it. Work merged since the last release streams behind a comet at the front, a knot for each week. Pick a star, or switch to **List**, to read its changelog section (else the release's notes) and every merged pull request it shipped, each linked to GitHub. A project without releases shows the comet alone, and tags stand in where there are no GitHub releases. Visitors to the hosted preview see it too ([#484](https://github.com/anthonyturner/observatory/pull/484)).
- Every page shows Claude Code usage in a slim strip at the top centre: the 5-hour window and the weekly limit as percents with small meters, turning amber from 80%, and when the one nearer its limit resets. A limit that has reset reads — rather than an old number, and the strip hides when there is no usage to read. The arrow folds it to a chip with just the higher percent, remembered in this browser; each page's header sits below it ([#488](https://github.com/anthonyturner/observatory/pull/488)).
- The playlist's **Video** switch works on the Review Queue too: it plays the video full screen behind the stars, dimmed beneath deep space so the galaxy glows over it and the stars, labels and cards stay readable, and faintly through the list view. Switching it off, or leaving the page, puts the video back in its window by the bar. Visual, Sky and Sync stay on Home ([#486](https://github.com/anthonyturner/observatory/pull/486)).
- The Review Queue has a weekly retro: press **Retro** in the tools for the week's merged and closed pull requests. **Where they waited** shows the hours they spent unable to merge, with checks failing, unsettled, with no issue linked or waiting on you, counted from the queue's own refreshes, since GitHub keeps no history of those states; a note says how many it saw. **Cycle time** charts the median time from open to merge for each of the last eight weeks, and **By agent** shows the week's merges by the agent that opened each one, as the Agents cards attribute them. Hover any bar for its numbers ([#471](https://github.com/anthonyturner/observatory/pull/471)).
- Jev triages the Review Queue from Home, typed or by push-to-talk alike: “what’s blocking?” reads out the top three pull requests across your projects, blocked first; “next star” opens the one Next star would pick, after a second with Stay here; “snooze 412 till Monday” (or tomorrow, for 3 days) and “dismiss 412” ask first, aloud and with Yes and No buttons, and change nothing until you say or type yes. Matched on your own machine with no model, so they work with Jev off ([#473](https://github.com/anthonyturner/observatory/pull/473)).
- Stacked pull requests show as **chains** on the Review Queue: a silver chain joins each one to the pull request it is built on, and the list and card say what it is stacked on and what is stacked on it. When a base merges, its children keep a broken gold chain marked _base merged · update_, and their card and PR screen offer Send crew to update them: the crew merges in where the base landed and points the pull request there, never rebasing ([#466](https://github.com/anthonyturner/observatory/pull/466)).
- The Review Queue nudges you to finish work before starting more: past a work-in-progress limit of 8 open pull requests, drafts aside, the comets for unclaimed issues fade and a note under the search suggests finishing one first. Nothing is blocked, and the faded comets still open. Set the limit with **wip** in the tools; getting back within it brightens the comets again ([#469](https://github.com/anthonyturner/observatory/pull/469)).
- The Review Queue spots flaky checks: a check that failed and then passed when rerun on the same commit, in any recent GitHub Actions run, is marked flaky. A pull request failing only on flaky checks no longer counts as failing; its card says which checks are flaky and has a **Rerun** button that runs the failed jobs again on GitHub, and the PR screen's Checks tab tags each flaky failure. Visitors to the hosted preview see the tags but no button ([#456](https://github.com/anthonyturner/observatory/pull/456)).
- The playlist has stations: the **Station** picker, where the Mix button was, tunes to Music, AI, Git & GitHub or Learn. Each tech station plays a shuffled list of hand-picked talks and tutorials from channels such as Fireship, Andrej Karpathy, 3Blue1Brown, GitHub, ByteByteGo and freeCodeCamp, with its own colours in the sky. The ♥ button still plays your favourites, and pressing it again goes back to the station ([#463](https://github.com/anthonyturner/observatory/pull/463)).
- The Review Queue has a time-boxed review **Sprint**: pick 15, 25 or 45 minutes and the queue fills it, in queue order with Next star's pick first, with the pull requests whose size fits (each budgeted 2 minutes plus 500 changed lines an hour). Its stars stay lit while the rest dim, a timer counts down, Next star works through it, and opening a pull request counts it as reviewed. End it early or let the time run out for a summary of what merged, what you reviewed and what was skipped. The timer's bar steps rather than glides when motion is off ([#451](https://github.com/anthonyturner/observatory/pull/451)).
- The playlist's video window has a **Smaller** button beside Bigger: it shrinks the video to a 200 × 200 square, the smallest YouTube allows, so on a phone it no longer spans the screen, and the music plays on. Smaller and Bigger each turn the other off, and the size is remembered next visit ([#454](https://github.com/anthonyturner/observatory/pull/454)).
- Resting the pointer on a Review Queue star shows its risk at a glance: a low, medium or high tag on its card, with what raised it — auth, migrations, config, CI, dependencies, or a broad change. On your own machine with an OpenRouter key, a one-line summary of what the change does follows, written once per pushed commit; without a key, or on the hosted site, the tag shows alone ([#452](https://github.com/anthonyturner/observatory/pull/452)).
- The Review Queue has a black hole at its centre that pulls in neglected work: a pull request left idle past a threshold (14 days, set with **hole** in the tools) spirals slowly toward it, further the longer it waits, its light reddening and stretching toward the hole while its colour still shows its group. Stars stop short of the hole, so none disappears, and the card says "Falling in: idle 23 days". A commit, a review, a snooze ending or a merge resets the count and the star moves back out on the next refresh. With motion off it holds still ([#448](https://github.com/anthonyturner/observatory/pull/448)).
- The Review Queue shows what changed since you last looked at a pull request. Marking it seen or opening its PR screen records its head commit; when new commits land, its star card says "3 new commits since you looked", and the PR screen's Diff tab opens on **Since last look**, just the changes after that commit, with a switch back to the full diff. After a force-push the card says it changed and the Diff tab shows the full diff with a note ([#447](https://github.com/anthonyturner/observatory/pull/447)).
- Send a crew to a stuck pull request: on your own machine, a conflicted or failing pull request's card and screen have **Send crew**. A Claude Code task merges the base branch into a conflicted branch, or fixes failing checks, and pushes to the pull request's branch; it never merges it. A small astronaut ship circles the star while the crew works, parked beside it when motion is off, then flies off with a green tick or a red cross. One crew or task runs at a time, the button says when one is out, and the card shows how the crew stands with a link to its log on Home. The hosted site has no button ([#445](https://github.com/anthonyturner/observatory/pull/445)).
- The Review Queue has a **Next star** button, or press n: it flies to the one pull request to work next, lights it with its card, then opens its PR screen. It picks from the most blocked group, takes the merge plan's first step when that is there, else the one idle longest, with a quick win breaking a tie, and skips drafts, snoozed and dismissed ones. Its tooltip names the pull request and why; with nothing to work it is greyed out ([#444](https://github.com/anthonyturner/observatory/pull/444)).
- Phones get Sync: press it, allow the microphone, and the sky moves with the real sound the phone hears, music from its own speaker included. The Beat slider shows too. The mic hears the room, so with headphones on it hears none of the music; it opens only when you press Sync, never with Play, and nothing is recorded or sent ([#430](https://github.com/anthonyturner/observatory/pull/430)).
- Sync can hear the computer’s sound card: with Observatory running on your Windows PC, pick **Sound card** and the sky follows whatever the computer plays, in any browser, with no share prompt and nothing to set up. The local server reads the speakers’ output and streams it to the page; it is offered only where that server can, never on the hosted site ([#427](https://github.com/anthonyturner/observatory/pull/427)).
- Sync can listen to an audio input device, in any desktop browser, Firefox and Safari included: pick **Input device** from the arrow beside Sync, allow access, and choose an input by name. A loopback input such as Stereo Mix, VB-Audio Virtual Cable or BlackHole carries the computer's own sound; a microphone hears the room. The input is remembered, and if it is unplugged the arrow turns to a ! and Sync falls back to the default input. In Firefox and Safari, whose screen shares never carry sound, Input device takes the place of This tab. The README says how to set up a loopback input ([#428](https://github.com/anthonyturner/observatory/pull/428)).
- Sync can hear the whole computer, not just this tab: the arrow beside Sync picks This tab (the default) or Whole computer, which asks to share a screen with its system audio, so the sky moves with Spotify, another tab or a game. Whole computer is offered in Chrome and Edge on Windows and ChromeOS only, where the browser can share system audio; the pick is remembered, and a share without sound says which box to tick ([#426](https://github.com/anthonyturner/observatory/pull/426)).
- The Done list filters: press merged, closed, issue done or dropped, each with its count, to list only that kind and dim the rest of the Spiral of Done; press it again to see everything ([#425](https://github.com/anthonyturner/observatory/pull/425)).
- The Review Queue's search finds finished work too: every pull request merged or closed and every issue closed on the Done list, listed after open work and tagged merged, closed, done or dropped. Picking one opens it and lights it on the Spiral of Done, with the Done list open ([#420](https://github.com/anthonyturner/observatory/pull/420)).
- The Orrery's Milky Way is made of what you shipped: every pull request merged in the last 60 days across your projects is a speck in the band, in its project's colour, oldest at one end and newest at the other. Rest the pointer on one to see what it was; click it to open that project's review queue ([#410](https://github.com/anthonyturner/observatory/pull/410)).
- The Review Queue's spiral galaxy is now the Spiral of Done: every pull request merged or closed and every issue closed in the last 60 days is a light on its arms, newest at the tips and older work winding in to the core, spiralling into place when the page opens. Rest the pointer on a light to see what it was, click it to open it, and press Done for the same work listed by day ([#407](https://github.com/anthonyturner/observatory/pull/407)).
- The Review Queue's sky has a spiral galaxy of its own, seen at a tilt up and to the right, with a warm core, bluish arms and pink star-forming knots that turn very slowly, behind a star field of mostly faint stars and a few bright ones. It holds still when motion is off ([#404](https://github.com/anthonyturner/observatory/pull/404)).
- The Orrery's sky has a Milky Way: a soft band of galaxy glow with dark dust lanes and a haze of faint stars, behind a richer star field of mostly faint stars and a few bright ones. The whole sky turns very slowly and shifts a little as you pan and zoom, and holds still when motion is off ([#400](https://github.com/anthonyturner/observatory/pull/400)).
- You can answer Jev's "Would you like to open any of them?" by push-to-talk: say its number ("12", "twelve", "number 12", "pull request 12", "issue 12"), its place ("the first one" to "the fifth one", "the last one") or a word only its title has, and Jev opens it after a second, with Stay here. "No", "no thanks" or "nope" closes the card; "yes" opens the only item, or asks which one when there are several; "all of them" gets "I can open one at a time". When he can't tell which you mean he says what he heard (aloud only the first time), keeps the card and puts your words in the box. Anything else you say is taken as a request, as before ([#391](https://github.com/anthonyturner/observatory/pull/391)).
- On your own machine with Speak on, when Jev's news names a pull request that was opened or a new issue, and Home's Ask panel is on screen, he ends by asking whether to open it ("Would you like to open any of them?"), and a card on Home lists each one with an Open button and No thanks. Open goes straight to the pull request's screen or the issue's window on its Review Queue. The question closes after 2 minutes with no answer, when you send a request or when you leave Home, and later news waits until it does ([#382](https://github.com/anthonyturner/observatory/pull/382)).
- The Review Queue has a search box under its legend: type a pull request's or issue's title, or its number, and press Enter or Go. A pull request, or an issue an open pull request closes, flies to that star and opens its card; an unclaimed issue rings its comet and opens its card; any other issue opens in its window. Clicking the box opens a list of the open pull requests and known issues that narrows as you type and closes when you move or click away; a search that finds nothing says so ([#369](https://github.com/anthonyturner/observatory/pull/369), [#384](https://github.com/anthonyturner/observatory/pull/384)).
- Zoom in on the Review Queue and each pull request's star shows a small planet for every issue it closes, up to four, and its review cost becomes a slowly turning disc of glowing gas, larger and brighter the more lines change (green for a quick win, none under twenty lines). A star with no planets closes no issue ([#365](https://github.com/anthonyturner/observatory/pull/365)).
- Review Queue stars look like real stars as you zoom in, and their kind shows what each pull request is waiting on: a blocked one is a deep giant that throws flares, more often the longer it waits; one GitHub has not settled hides in a veil of gas; one waiting on you burns clear with spikes; one you saw recently rests small and calm. Zoomed out they stay calm points ([#362](https://github.com/anthonyturner/observatory/pull/362)).
- Orrery worlds have drifting clouds that shade the ground, and their night sides carry news: city lights show work in motion (more open pull requests, more lights, fading as the oldest goes stale), and glowing fissures appear only while checks are failing. Rings for branches that no longer merge are thin see-through bands, crossed by their world's shadow ([#358](https://github.com/anthonyturner/observatory/pull/358)).

### Changed

- Jev understands Review Queue commands said the way people speak: “um, hey Jev, I want to snooze P.R. four twelve tell Monday”, “dismissed PR412” and “send a through to 412” now work. Numbers up to 9999 are heard, including “four twelve” and “four hundred and twelve”; fillers, Jev’s name as “Jeff” or “Jeb”, and extra words around the command are passed over; and a project’s name may be slightly misheard. Snooze and dismiss still ask yes or no first. When Jev can’t make out a snooze or dismissal he says what he heard and the command he can do, as in “I heard: ‘snooze 412 till the cows come home’. Did you mean ‘snooze 412 till Monday’?” ([#511](https://github.com/anthonyturner/observatory/pull/511)).
- Push-to-talk mishears Jev's commands less. Both ways of hearing now listen in English and expect the words the commands use: “Jev”, crew, snooze, dismiss, pull request, Next star, your project and repository names, and your open pull requests' numbers, so “Jev” no longer comes back as “Jeff”. ElevenLabs hears with its Scribe v2 model, which costs a fifth more per recording with these words, and the speech model in the browser is now the English-only Whisper base.en, a download the same size as before ([#512](https://github.com/anthonyturner/observatory/pull/512)).

### Security

- The local API now refuses, on every route, a request that does not come from this machine: a website open in another tab can no longer read your pull requests, logs or usage, or merge or edit a pull request, by pointing its own address at your computer ([#317](https://github.com/anthonyturner/observatory/pull/317)).
- Jev, answering through Claude Code, can still search the web but can no longer fetch a page at an address of its own choosing, so text a stranger writes in an issue or pull request title cannot talk it into sending your private project details to another site ([#316](https://github.com/anthonyturner/observatory/pull/316)).
